## Source-screen performance

The substantive-proof screen checks full canonical before/current assertions,
independently of model-selected proof subsets. It ignores conservative prose
formatting while preserving quoted literals, identifiers, numbers and meaningful
operators. Full-assertion current intervals identify reflow without quadratic
character alignment. Cached comparisons and a 200,000 occurrence work limit
bound repetitive matching; exceptional work-limit sources abstain on fresh
support instead of bypassing the check. Code/indentation subtleties can still
cause conservative abstention; this is not a semantic entailment engine.

On actual captures, 283 safe added-line checks plus catalog construction took
0.3841 seconds in this local run.
The repeated-character synthetic stress was about 0.003 seconds at 6,000
characters and 0.012 seconds at 24,000. Those long single-line helper stress
inputs exceed the normal 650-character citation bound; a separate 20-line
bounded-source regression exercises the actual catalog. Measurements depend on
hardware; no hosted latency or dollar-cost advantage is established.
