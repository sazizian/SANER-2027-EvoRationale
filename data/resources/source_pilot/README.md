# Supplemental source-pilot resources

These are unchanged English resource files from the source-pilot checkpoint ZIP included in the uploaded project. The two original reviewer workbooks are in ../../excel/source_pilot_workbooks/.

The JSON summaries, rejection CSV and LaTeX insertion describe a separate ABC study. They are supplied source claims, not EvoRationale exact-triple F1 measurements or KEP 1287 Gold. The parent hosted request/response audit log, runner, raw upstream source-packet files and adjudicated comparative ABC output judgments are absent from the supplied checkpoint ZIP. This package does not independently repeat that study.

EXTRACTION_PROVENANCE.json records source ZIP and member hashes. Original labels and workbook contents remain unchanged. Do not combine these counts with data/results/summary.csv or use these review workbooks as inference input.
