# Project Artifact Language Convention

All saved project deliverables must be written in English:

- Python source code, comments, docstrings, error messages, test names, and scripts.
- CSV headers and values, JSON keys and values, file and folder names, and manifest descriptions.
- Research notes, reports, readme files, paper text, tables, figure labels, and prompts stored as files.
- Any new evidence annotation or proposed decision-state field.

Conversation-level explanations may be provided in the user's preferred language, but do not copy non-English explanations into saved research or code artifacts.

Keep original source quotations verbatim when evidence fidelity requires it, and clearly label the original source language. This English-only review package itself contains no non-English text.
